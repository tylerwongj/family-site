Let ChatGPT use your computer

It clicks and types in your apps while you watch. You can stop it any time.

You need

ChatGPT desktop appWindows or Mac. Not the website or phone app.
A paid planPlus or higher
A supported countryNot available everywhere yet

Set it up

  1. Get the app from OpenAI

    Only from chatgpt.com/download. Install it and sign in.

  2. Switch to Work

    In the app, pick ChatGPT and switch to Work (or pick Codex).

  3. Turn on Computer Use

    Plugins → Computer Use → Install plugin (or Enable). Switch both toggles on, then Try now.

  4. Allow it (Mac only)

    System Settings → Privacy & Security: allow Screen Recording and Accessibility. Windows needs nothing extra, but ChatGPT takes over the screen while it works.

  5. Ask it

    Type @Computer and say exactly which app and what to do.

    @Computer In Notes, make a grocery list: milk, eggs, bread.

Stay safe

  • One app, one small job at a time
  • Close banking and email you don't need
  • Wrong window? Stop it right away
  • Passwords, payments, security prompts: you do those
  • "Always allow" only apps you fully trust
  • What it does while signed in counts as you
